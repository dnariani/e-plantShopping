# e-plantShopping

## Paradise Nursery
This is a online plant shopping application made with React.
The application allow you to browse a variety of houseplants. add them to a shopping cart, view things in the shopping cart and their total cost and be able to adjust the number of items in the cart before checkout.

## Description
Paradise Nursery is an online plant shopping application built with React and Redux. The application allows users to browse different houseplants, add items to a shopping cart, view item quantities and total costs, and dynamically adjust quantities or remove items before proceeding to checkout.

## Features
- Landing Page
- Product Catalog
- Header Navigation
- Shopping Cart
- Cart Controls
